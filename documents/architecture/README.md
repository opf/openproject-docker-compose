# Architecture Documentation

This directory contains system architecture and design specifications for the OpenProject Docker Compose system.

## Documents

### **ARCHITECTURE.md**
- **Purpose**: Comprehensive system architecture documentation
- **Audience**: Developers, system administrators, architects
- **Content**: Component interactions, data flow, technical specifications
- **Scope**: Complete system overview with implementation details

### **INTERACTIVE_CONFIG_ARCHITECTURE.md**  
- **Purpose**: Interactive configuration system design and workflows
- **Audience**: Developers working on configuration management
- **Content**: Configuration flow architecture, user interaction patterns
- **Scope**: Focused on the interactive configuration subsystem

## Usage

These documents provide the technical foundation for understanding how the OpenProject Docker Compose system is architected. Start with `ARCHITECTURE.md` for the big picture, then dive into specific component architecture documents as needed.
