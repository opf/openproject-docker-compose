# User and Developer Guides

This directory contains practical guides for working with the OpenProject Docker Compose system.

## Documents

### **SUBMODULES_GUIDE.md**
- **Purpose**: Guide for working with Git submodules in this project
- **Audience**: Developers, contributors, system administrators
- **Content**: Submodule setup, management, troubleshooting
- **Scope**: Git workflow and repository management

### **MANAGER_FOLDERS.md**
- **Purpose**: Guide to manager component organization and structure
- **Audience**: Developers working on manager components
- **Content**: Folder structure, component relationships, organization patterns
- **Scope**: Code organization and component architecture

## Usage

These guides provide step-by-step instructions and best practices for common tasks. They're designed to be practical references that you can follow to accomplish specific goals.
