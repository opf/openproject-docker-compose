# Migration and Rebuild Documentation

This directory contains migration plans, rebuild documentation, and evolution tracking for the OpenProject Docker Compose system.

## Documents

### **MIGRATION_PLAN.md**
- **Purpose**: Comprehensive migration strategy and implementation plan
- **Audience**: Project leads, developers, system architects
- **Content**: Migration phases, component transitions, implementation roadmap
- **Scope**: Complete system evolution from current to target state

### **PYTHON_REBUILD.md**
- **Purpose**: Python rebuild phases and progress tracking
- **Audience**: Developers working on Python components
- **Content**: Rebuild status, completed features, current phase progress
- **Scope**: Python-specific modernization and development tracking

## Usage

These documents track the ongoing evolution of the system. They're living documents that are updated as migration and rebuild work progresses.

- **MIGRATION_PLAN.md** provides the overall strategy and roadmap
- **PYTHON_REBUILD.md** tracks specific Python development progress
